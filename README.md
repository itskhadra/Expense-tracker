# Expense Tracker

## Description
The Expense Tracker is a web application that helps users record and manage their expenses in different currencies.

## Features
- Add and track expenses.
- View recorded expenses.
- Style the application with CSS.
- Organize the project using HTML, CSS, and JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
